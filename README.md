# 🎨 Image Color Palette

A lightweight Python CLI tool that extracts dominant colors from an image and displays their RGB and HEX values.

## Features

- Extract dominant colors
- Display RGB values
- Generate HEX codes
- Works with common image formats
- Simple CLI interface

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Example

```text
🎨 Image Color Palette
========================================

Enter image path: wallpaper.jpg

🎨 Dominant Colors
========================================

1. RGB(32, 41, 55)  HEX #202937
2. RGB(214, 198, 174) HEX #D6C6AE
3. RGB(89, 72, 61)  HEX #59483D
4. RGB(142, 125, 108) HEX #8E7D6C
5. RGB(240, 235, 226) HEX #F0EBE2
```
